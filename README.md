# Лабораторна робота 2 (фінал)

Реалізація скінченного автомата (FSM) для перевірки рядків за регулярним виразом

## Пояснення імплементації

### Структура станів

Автомат складається з таких класів-станів

StartState - початковий стан; зберігає список усіх токенів патерну у next_states
TerminationState - термінальний стан
DotState- приймає будь-який символ
AsciiState - приймає конкретний символ; check_self повертає self при збігу або None при незбігу
StarState - обгортає попередній стан; приймає 0 або більше входжень
PlusState - обгортає попередній стан; приймає 1 або більше входжень

### Побудова автомата

Оригінальна заготовка будує пласку структуру: prev_state не оновлюється в циклі, тому всі токени патерну додаються напряму до Start.next_states у порядку їх появи:

Коли зустрічається * або +, попередній стан видаляється з prev_state.next_states і передається всередину StarState/PlusState як checking_state. Star(a).check_self('a') повертає True, а Star(a).check_self('4') -False

# Ініціалізації
```
self.next_states = []  # instance-level, не class-level
self.curr_sym = symbol  # instance-level для AsciiState
```
Без цього всі екземпляри одного класу ділять один список next_states та одне значення curr_sym
### Перевірка рядка
Оскільки структура пласка check_string реалізує рекурсивний NFA з мемоізацією: паралельно проходить по індексу токена i в states і індексу символу j у рядку

StarState спочатку пробує пропустити (match(i+1, j)), потім спожити символ і залишитись (match(i, j+1)
PlusState вимагає хоча б один символ, потім жадібно забирає решту з можливістю раннього виходу
Інші стани перевіряють символ і рухаються вперед (match(i+1, j+1))

Словник memo кешує вже обчислені (i, j) пари, що запобігає повторним обчисленням
